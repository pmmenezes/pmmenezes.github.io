# Por que Logs Estruturados?

Texto puro é bom para humanos, JSON é melhor para máquinas e ferramentas de observabilidade.

## O que muda?
- Filtros precisos por `request_id`.
- Dashboards automáticos.
- Integração nativa com ELK/CloudWatch/Grafana.
